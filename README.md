# NovaChat

NovaChat is a modern AI chatbot inspired by ChatGPT, built using Node.js, Express, Gemini API, HTML, CSS, and JavaScript.

---

## ✨ Features

- 🤖 AI-powered conversations
- 🌑 Premium dark futuristic UI
- 📝 Markdown formatted responses
- ⚡ Fast Gemini 3.5 Flash integration
- 📱 Responsive design
- 💬 ChatGPT-inspired interface
- 🎨 Smooth animations and gradients

---

## 🛠️ Tech Stack

- HTML
- CSS
- JavaScript
- Node.js
- Express.js
- Gemini API

🚀 Installation

Clone the repository:

git clone https://github.com/NishkarshHublikar/NovaChat.git

Move into the project folder:

cd NovaChat

Install dependencies:

npm install
🔑 Environment Variables

Create a .env file in the root folder:

GEMINI_API_KEY=your_api_key_here

Get your Gemini API key from:

https://aistudio.google.com/app/apikey

▶️ Run Locally

Start the server:

node server.js

Open in browser:

http://localhost:3000
